What this check shows

It shows that the calculator evaluates ISO 5167-2 correctly: the Reader-Harris/Gallagher discharge coefficient, the expansibility factor, the iteration on Reynolds number, the permanent pressure loss, and the standard's limits of use.

It does not make the ISO equation more accurate than the standard says it is. ISO 5167-2 gives the uncertainty of the discharge coefficient as 0.5 % for 0.2 ≤ β ≤ 0.6, larger outside that range and in pipes smaller than 71.12 mm.

A real installation adds the uncertainty of the differential-pressure and density measurements, the condition of the plate edge, pipe roughness and upstream straight lengths.

Method

Each case was run through the calculator's server code, the same code that serves the calculator page. The results were compared with two references written independently of it:

  1. fluids, an open-source Python library for fluid mechanics (version 1.3.1). Its orifice functions implement ISO 5167-2 and ASME MFC-3M.
  2. A separate implementation written directly from the equations in ISO 5167-2:2003 §5.3.2, which the 2022 edition did not change.

The two references agree with each other to machine precision on every case. Mass flow is solved by iterating between the flow equation and the Reynolds-number-dependent C until C stops changing. Each reference uses the same density and viscosity as the calculator, so the comparison isolates the flow equations. Steam density is checked separately, below.

One detail: fluids adds two low-Reynolds-number terms from later work by Reader-Harris that are not in ISO 5167-2. Both are zero above ReD ≈ 3 700. Every case here is above the ISO minimum of 5 000, so the comparison is against the ISO equation alone.

Check it yourself

Case L2 (water, flange taps) with the same reference library. Enter the same values in the calculator and compare.

# pip install fluids==1.3.1
from fluids.flow_meter import differential_pressure_meter_solver, differential_pressure_meter_C_epsilon

# D = 100 mm, d = 50 mm, Δp = 25 kPa, water ρ = 998 kg/m³, μ = 1.0 mPa·s
# (k = 1e20 makes ε = 1, as for a liquid)
args = dict(D=0.100, D2=0.050, P1=200000, P2=175000, rho=998, mu=1.0e-3, k=1e20,
            meter_type='ISO 5167 orifice', taps='flange')
m = differential_pressure_meter_solver(**args)
C, eps = differential_pressure_meter_C_epsilon(m=m, **args)
print(f"m = {m:.6f} kg/s  C = {C:.6f}")   # m = 8.680648 kg/s  C = 0.605979

Change log

  • 22 Oct 2026Steam density corrected. Four IAPWS-IF97 Region 2 coefficients in the steam-density routine had the wrong power of ten. The error was negligible at low pressure but grew with pressure: +0.4 % at 11 bar a and 200 °C, +2.2 % at 40 bar a and 300 °C, and +8.7 % at 60 bar a and 300 °C. The largest error in the test grid was 20 %, at 160 bar a and 400 °C. Mass flow varies with √ρ, so superheated-steam flows were high by roughly half these figures. Liquid and gas results were not affected.
  • 22 Oct 2026Limits of use aligned with ISO 5167-2:2022 §5.3.1. β now starts at 0.10 (was 0.20), the 12.5 mm minimum bore is checked, and the Reynolds-number limit depends on the tapping type and β. The previous fixed table was stricter than the standard and warned on some valid inputs. Calculated values did not change.
  • 22 Oct 2026Formula reference corrected. The calculator page now shows the 2003/2022 expansibility equation, which the calculation was already using.
